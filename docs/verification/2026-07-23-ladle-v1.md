## Defects found and corrected during comparison

1. Custom fixed-size typography did not scale with Dynamic Type.
   The Ladle type system now uses `@ScaledMetric` while retaining the reference
   sizes at the default category.
2. Two-column cards, metadata bands, filter choices, editor controls, and
   section headers crowded at accessibility sizes.
   They now collapse, wrap, or stack according to the active Dynamic Type size.
3. Search, clear, and editor reorder controls exposed hit regions below the
   intended 44-point minimum.
   Their semantic frames now meet the platform target.
4. Recipe grid/list containers lacked button traits even though they exposed
   open actions.
   They now identify as buttons without hiding their nested favorite actions.
5. Press and welcome transitions ignored Reduce Motion.
   Motion-sensitive scaling and movement are now suppressed when requested.
6. Large pending-import cards compressed their status and source text.
   Accessibility-size cards now stack the import description and status pill.
7. A scrolled library could paint section text beneath the status bar.
   The library now masks the current window safe-area region with the paper
   background while preserving the initial custom header layout.
8. XCTest lifecycle setup emitted Swift 6 main-actor isolation warnings.
   SwiftData fixtures are now created locally inside main-actor test methods.

## Behavioral invariants rechecked

- Only `.ready` imports schedule completion notifications.
- Notification denial cannot roll back recipe or import-job persistence.
- Timer notifications are not requested until an explicit timer start.
- Health authorization is not requested until the final export confirmation.
- Failed and needs-review re-import candidates never replace the current recipe.
- Share envelopes remain queued after persistence failure and reconcile exactly
  once after recovery.
- UI tests use disabled notification services, so system prompts cannot obscure
  deterministic flows.
