# Gemini 3.7 Live Import Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Make Gemini 3.7 Flash the default OpenRouter recipe model and run the five user-supplied social posts once through Ladle's live acquisition and recipe-processing stages.

**Architecture:** Change only the model default used by extraction, creator search, and targeted verification; keep the explicit environment override intact. Use an ignored, one-run probe harness to assemble the same acquisition, evidence gate, extraction, deterministic review, USDA nutrition, and targeted verification components without mutating the persistent recipe database.

**Tech Stack:** Python 3.12, Pydantic Settings, httpx, OpenRouter structured output, USDA FoodData Central, pytest, Ruff, mypy.

### Task 3: Prepare the one-run live probe

- Create, ignored: `Backend/.eval-cache/live-imports/2026-08-24-gemini-3.7-results.json`

**Step 1: Build the ignored probe harness**

The harness must:

1. hard-code only the five supplied public URLs;
2. canonicalize them with `SourceIdentityParser`;
3. build `SourceVideoDescriptor` values with stable URL-derived UUIDs;
4. acquire text through the configured free, audio-transcription, and creator-
   search rungs;
5. call `require_recipe_evidence` before any extraction;
6. call the existing evaluation pipeline with the configured 3.7 model so
   extraction, review, creator-fact recovery, USDA nutrition, and verification
   stay identical to the production components;
7. capture acquisition diagnostics, source evidence, the final recipe template,
   extraction/verification usage, reported USD cost, elapsed time, and failures;
8. redact credentials and headers by never serializing settings or HTTP clients;
9. write the result file after every URL so an interrupted run preserves work;
10. process every URL exactly once, except for existing bounded HTTP 429 retries.

**Step 2: Validate the harness without network calls**

Run its `--list` mode and verify that it prints five canonical identities, four
